Preguntas frecuentes

Resolvemos tus dudas

¿Puedo importar mis productos desde Excel?

Sí. En la implementación cargamos tu catálogo, precios y stock desde una hoja de Excel o desde el sistema que uses actualmente.

¿Emite boletas y facturas electrónicas?

El sistema genera boletas y facturas. Para el envío electrónico se integra con un proveedor de facturación electrónica autorizado, disponible en el plan Empresa o como adicional.

¿Funciona en celular o tablet?

Sí, se usa desde el navegador en PC, laptop, tablet o celular. Ideal para consultar stock desde el almacén.

¿Qué pasa si se va el internet?

Podemos configurar la caja para seguir registrando ventas y sincronizar cuando vuelva la conexión (según el plan contratado).
